# Trust
This plugin allows players to trust each other to prevent killing each other.

Add the Trust-<version>.jar into the plugins folder of your Minecraft server.

## Commands
- `/trust <player>` - Allows you to trust a player.
    - permission - trust.use
- `/trustlist` - Shows trusted players.
    - permission - trust.use
- `/untrust <player>` - Untrust a player.
    - permission - trust.untrust
